# ClickPop — پلتفرم خدمات شبکه‌های اجتماعی

مخزن توسعهٔ **کلیک‌پاپ / ClickPop** (`clickpop.ir`): تم سفارشی وردپرس + افزونهٔ «ClickPop Core Engine».

## وضعیت

فاز **F1–F5 — نسخهٔ قابل نصب**. تم و افزونه نوشته و بسته‌بندی شده‌اند.

```
dist/clickpop-theme.zip   ← تم، آمادهٔ نصب از پیشخوان
dist/clickpop-core.zip    ← افزونه، آمادهٔ نصب از پیشخوان
```

راهنمای گام‌به‌گام نصب: [`docs/08-INSTALL-GUIDE.md`](docs/08-INSTALL-GUIDE.md)

### آنچه کار می‌کند

اتصال به SMM API v2 · همگام‌سازی سرویس با تفاوت‌گیری hash · موتور سود چندسطحی ·
کیف پول با دفتر کل فقط-افزودنی و برداشت اتمیک · ثبت سفارش با Saga دوفازی و کلید idempotency ·
بازگشت وجه خودکار سفارش ناقص/لغوشده · درگاه زرین‌پال با تأیید سمت سرور ·
داشبورد کاربر · پنل مدیریت · ۵ ویجت المنتور · دارک‌مود بدون فلیکر · Schema.org

### آنچه هنوز نیست

ورود با OTP · درگاه‌های آیدی‌پی/نکست‌پی · رابط پاسخ تیکت در ادمین · فایل‌های ترجمهٔ en/ru/zh
(فهرست کامل در انتهای راهنمای نصب)

### تست

```bash
php tests/smoke.php   # ۳۳ تست روی منطق پول، تاریخ شمسی، اعتبارسنجی لینک و نگاشت وضعیت
```

## اصول غیرقابل‌مذاکره

1. پول = عدد صحیح ریال. هیچ float در مسیر مالی.
2. دفتر کل فقط-افزودنی. موجودی، حاصل جمع دفتر است.
3. تراکنش دیتابیس هرگز روی I/O شبکه باز نمی‌ماند.
4. قیمت همیشه سمت سرور محاسبه می‌شود.
5. تم هیچ منطق تجاری و هیچ SQL ندارد.
6. هر ورودی sanitize، هر خروجی escape، هر کوئری prepare.
7. یک شیت CSS برای RTL و LTR (logical properties).
8. صفر وابستگی رانتایم خارجی؛ بدون CDN.
