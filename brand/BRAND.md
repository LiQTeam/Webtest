# clickPop — راهنمای هویت بصری (Brand Guidelines v1.0)

## ۱. مفهوم طراحی

- **حلقهٔ آبی (C):** حرف اول `clickPop` + استعارهٔ «رشد / چرخهٔ تعامل». دهانهٔ باز حلقه در راستای ۴۵ درجه، حسِ حرکت و پیشرفت می‌دهد.
- **نشانگر نارنجی (Cursor):** هستهٔ برند — «کلیک». همزمان به‌عنوان **فلش رشد** (Growth Arrow) خوانده می‌شود که از حلقه بیرون می‌زند؛ یعنی «افزایش فالوور/ویو/ممبر».
- **نقطهٔ نارنجی روی `i`:** همان «Pop» در مقیاس کوچک — پیوند بصری میان نشانه و لوگوتایپ.
- **هندسه:** کل نشانه از یک شبکهٔ واحد ساخته شده (شعاع حلقه ۱۴۸، ضخامت ۵۶، دهانه ۹۴°، محور نشانگر ۴۵°). لوگوتایپ نیز کاملاً هندسی و از دایره/خط ساخته شده — بدون وابستگی به هیچ فونت خارجی. هیچ متنی به فونت وابسته نیست، پس روی هر سیستمی یکسان رندر می‌شود.

## ۳. نسخه‌ها و کاربرد

| فایل | کاربرد |
|---|---|
| `clickpop-logo-horizontal` | نسخهٔ اصلی — هدر سایت، فاکتور، امضای ایمیل |
| `clickpop-logo-stacked` | فضای عمودی/مربعی — پوستر، استوری، بنر |
| `clickpop-icon` | نشانه تنها — فاوآیکن، آواتار، واترمارک |
| `clickpop-app-icon` | کاشی مربع گرد (Squircle) — آیکن اپ، آواتار تلگرام/اینستاگرام |
| `*-ondark` | پس‌زمینهٔ تیره (حلقه سفید + نشانگر نارنجی) |
| `*-white` | تک‌رنگ سفید — روی عکس/رنگ اشباع |
| `*-ink` | تک‌رنگ تیره — چاپ تک‌رنگ، فکس، مهر |
| `*-flat` | بدون گرادیان — چاپ افست، برش وینیل، گلدوزی |

## ۴. قوانین اجرا

- **Clear Space:** حداقل فاصلهٔ آزاد اطراف لوگو = ارتفاع حرف `o` در لوگوتایپ (≈ ۳۳٪ ارتفاع نشانه). هیچ عنصری وارد این ناحیه نشود.
- **حداقل اندازه:**
  - افقی: عرض ≥ ۱۲۰px (وب) / ۲۵mm (چاپ)
  - عمودی (stacked): عرض ≥ ۹۰px
  - نشانه تنها: ≥ ۲۴px
  - **زیر ۳۲px از نسخهٔ `app-icon` استفاده کن، نه `icon`** — کاشی پُر در ابعاد ریز خوانا‌تر است.
- **ممنوع:** کشیدن/فشردن غیرنسبتی، چرخاندن، تغییر رنگ، افزودن سایه یا Stroke، جابه‌جایی نشانگر نسبت به حلقه، بازنویسی لوگوتایپ با فونت دیگر، قرار دادن روی پس‌زمینهٔ شلوغ بدون نسخهٔ `white`.
- **کنتراست:** `#1668FF` روی سفید نسبت ۴.۲:۱ دارد — برای متن ریز از `Blue Deep` یا `Ink` استفاده کن (WCAG AA).

## ۵. پیاده‌سازی وب

```html
<!-- هدر -->
<img src="/brand/clickpop-logo-horizontal.svg" alt="clickPop" width="220" height="61">

<!-- فاوآیکن -->
<link rel="icon" href="/favicon.ico" sizes="16x16 32x32 48x48 64x64">
<link rel="icon" type="image/png" sizes="192x192" href="/brand/clickpop-app-icon-192.png">
<link rel="apple-touch-icon" sizes="180x180" href="/brand/clickpop-app-icon-180.png">
```

```css
:root{
  --cp-blue:#1668FF; --cp-blue-deep:#0B44D6; --cp-blue-light:#3D89FF;
  --cp-orange:#FF7A1A; --cp-orange-deep:#F2470F; --cp-ink:#0A1C3D;
  --cp-grad-blue:linear-gradient(135deg,#3D89FF,#0B44D6);
  --cp-grad-orange:linear-gradient(45deg,#F2470F,#FFA22A);
}
```

- SVG را با `Cache-Control: public, max-age=31536000, immutable` و Brotli سرو کن (هر فایل < 2.2KB).
- برای LCP، لوگوی هدر را **inline SVG** بگذار تا یک درخواست شبکه حذف شود؛ `loading="lazy"` روی لوگوی هدر نزن.
- عرض/ارتفاع را همیشه صریح بده تا CLS صفر بماند.
